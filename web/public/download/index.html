How to install

  1. Tap Download the app, then open the file when it finishes.
  2. If Android says it cannot install from this source, tap Settings and allow Install unknown apps for this browser, then go back and tap Install.
  3. If Play Protect says the app is unrecognised, tap More details, then Install anyway. This is normal for a test app that is not in the Play Store.
  4. Open School ERP and sign in with the login you were given.

Updating

When there is a new version, download it from this page and install it over the old one. Your signed-in accounts stay.

iPhone: not available yet. The web version works in any phone browser.
